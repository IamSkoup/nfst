# Проверки сборки 0.1

Дата повторной проверки: 26 октября 2026. Среда: Linux, Node.js 24.22.1, Python 3.12, Chromium 141 через Playwright 1.56.1. WebGL использовал программный SwiftShader. Результаты не являются измерением производительности на Windows или дискретной видеокарте.

## Подтверждено

- `npm ci --cache /workspace/.npm-cache`: установка из lockfile успешна, проверка целостности npm сохранена.
- `npm run build`: автономный IIFE-бандл с встроенным GLB успешно собран.
- `npm test`: **30 тестов прошли**, 0 неудачных, 0 пропущенных.
- `npm run test:browser`: **22 этапа проверки прошли**, ошибок JavaScript/console и внешних runtime-запросов нет.
- В браузерном сценарии с чистым профилем пройдены **все 12 событий карьеры, 14 заездов с учётом трёх этапов лиги**. Покупки выполнялись через интерфейс, на стартовые и заработанные деньги; завершение, награды и победы вычислялись игровой логикой.
- Автоматическое управление передавало обычные throttle/steer/brake/boost входы в физику с фиксированным шагом. Для ускорения теста игровое время симулировалось в цикле. Позиции, победы и баланс не подставлялись. Это не ручное прохождение человеком в реальном времени.
- Проверены покупка, отмена покупки, цена, сохранение после перезагрузки, блокировка будущего события, полный прогресс после перезагрузки, экспорт настоящего JSON-профиля.
- Реальные клавиатурные события проверяют разгон, переключение камеры, паузу, продолжение, карту свободного бега и правильные направления A/D и стрелок влево/вправо.
- Шипение адреналина: клавиатурный Shift запускает локальный звук, громкость становится положительной, ошибки декодирования отсутствуют; отпускание Shift выключает активный слой. Художественное сходство с NFS не измеряется этим тестом.
- Проверены интерфейсы в 1600×900 и 2560×1080, кнопка старта внутри экрана. Дополнительно осмотрены снимки 1440×900. Снимки и JSON-отчёт создаются в `test-results/`.
- В GLB реально присутствуют клипы Idle и Run. Модель отображается и анимируется в WebGL.
- Пользовательский исходный файл `тест` сохранён без изменений.

## Что проверяют 30 тестов симуляции

12 отдельных карьерных событий; неподвижность до старта; разгон/поворот/тормоз/расход адреналина/прыжок; столкновения; запрет финиша при пропуске контрольных точек; атомарная покупка; однократное начисление денег и отсутствие карьерных наград в быстрой гонке; истечение лимита Time Trial; запись действительной траектории призрака; отсутствие финиша и выплат в свободном беге; восстановление на другом берегу при медленном входе в каньон; валидация импортируемого профиля; шесть различных конечных геометрий; сопоставимое движение при 30/60/120 шагах в секунду. Добавлены проверки A/D/стрелок, линии финиша, широких поворотов, возврата к контрольной точке и завершения Drift без ожидания зависших соперников. Четвёртая гонка воспроизведена с управляемым дрифтом и успешно завершена на первом месте.

## Исправлено при проверке

Ранее исправлены пропуск ворот ИИ на тесных поворотах, дерево на маршруте, некорректная геометрия окружения, шрифты и компоновка интерфейса. В этой версии дополнительно исправлены направления клавиш в реально запускаемом бандле, слишком ранний зачёт финишной линии, пропущенные контрольные точки на широких поворотах, несогласованный прогресс после R, зависание персонажа при ожидании соперников в Drift. Для непрерывного заноса добавлено управление W + S вместе с поворотом. Полный сценарий браузерного теста завершён целиком.

## Непроверено и ограничения

- `file://`: попытка навигации в Chromium отклонена политикой среды (`ERR_BLOCKED_BY_ADMINISTRATOR`). **Тест не пройден и не объявляется успешным.** В сборке нет модульных импортов, fetch моделей или внешних CDN; это архитектурная совместимость, а не доказательство локального запуска на Windows. Предусмотрен серверный запускатель.
- Физическое двойное нажатие Windows Explorer, Chrome/Edge на Windows, поведение localStorage именно в file-origin, реальная частота 60 FPS и ручное прослушивание аудио не проверены.
- Уровень визуального исполнения — процедурная первая версия. Не выполнены требования ТЗ о финальных качественных канонических моделях, реалистичном окружении и профессиональной постановке. Азад пока использует вариант общей модели. Скутер и человек упрощены; точная модель EC-02, мимика, движения рук и подвески отсутствуют.
- Два основных клипа не заменяют полный набор анимаций из ТЗ. Вступления используют движущуюся камеру, letterbox и субтитры, но ещё не являются полноценными смонтированными кат-сценами. Финальная развязка дана на экране результатов.
- Реализовано 12 событий / 6 маршрутов, не 100–111. В свободном беге доступна единая поверхность 1140×1220 игровых метров; все перечисленные в ТЗ биомы, пещеры, водопады и глубокая проработка природы не созданы.
- Четыре музыкальных файла и базовые эффекты. Шипение адреналина — оригинальный сэмпл фильтрованного шума. Нет актёрских голосов, индивидуальной записи дыхания/шин/электромотора, полного набора погодных/природных эффектов или оригинальных композиций для каждого босса.
- Нет журналов, слоя наклеек на Фули, сложной системы репутации, ручной тонкой настройки каждого параметра камеры и полноценного графического профайлера. Эти функции не представлены работающими кнопками.

## Повторение

В каталоге игры: `npm ci`, `npm run build`, `npm test`. Поднять `python3 -m http.server 8080 --bind 127.0.0.1`, затем выполнить `npm run test:browser`. Файл `tests/browser.mjs` запускает отдельный чистый браузерный профиль, не меняя пользовательские сохранения обычного браузера.
