# THE LION GUARD: UNDERGROUND — сборка 0.1

Отдельная адаптация для смартфонов включена в эту копию. Инструкция по запуску на телефоне и сенсорным кнопкам находится в `README_MOBILE.md`.

Самостоятельная браузерная 3D-игра: Фули, ночная саванна, гонки, карьера и улучшения. Это первая играбельная версия, а не завершение всех художественных и содержательных требований мастер-ТЗ.

## Запуск

1. Полностью распакуйте каталог игры. Сохраняйте взаимное расположение `index.html`, `js`, `css`, `assets`.
2. Откройте `index.html` в современном Chrome или Edge. Скрипт классический, Three.js и GLB встроены в `js/game.bundle.js`; загрузка моделей не использует `fetch`, ES-модули или CDN. Шрифты и аудио лежат рядом.
3. **Запуск через `file://` не подтверждён:** Chromium облачной среды отклонил адрес административной политикой `ERR_BLOCKED_BY_ADMINISTRATOR`. Это не успешный тест двойного щелчка и не доказательство ошибки игры.
4. Проверенный способ — локальный сервер. На Windows запустите `START_WINDOWS.bat` (нужен установленный Python 3). На Linux/macOS: `bash START_LINUX.sh`. Адрес: `http://127.0.0.1:8080`. Сервер слушает только собственный компьютер. Если браузер открылся раньше сервера, обновите страницу. Закрытие окна сервера останавливает игру после перезагрузки страницы.
5. Музыка начинается после первого нажатия кнопки. Интернет, аккаунт, сервер в облаке и ключи API во время игры не нужны.

## Что играть

- 12 последовательных карьерных событий на 6 геометрически различных маршрутах. Лига состоит из трёх этапов, то есть полный путь включает 14 заездов.
- Sprint, Circuit, Drag (ритм лап), Drift (очки скольжения), Knockout, Time Trial, Street X, League, Outrun, Special и две финальные дуэли.
- Азад — гепард; Аздат — электроскутер Кайона. Это разные соперники. Внешность Кайона условная, портретного сходства не заявляется.
- Для открытия следующего события нужна победа. У проигрыша небольшая денежная награда. За повторную победу — 35% исходной суммы. В быстрой гонке карьера и деньги не меняются, статистика и рекорды учитываются.
- Шесть технических характеристик, по три уровня. Покупка требует подтверждения. Четыре бесплатных цветовых акцента; исходный цвет можно вернуть.
- Свободный бег, карта, пять камер, пауза, локальные сохранения, экспорт/импорт JSON.

## Управление

| Клавиша | Действие |
|---|---|
| W / ↑ | Разгон |
| S / ↓ | Торможение |
| A D / ← → | Поворот |
| Shift | Адреналин, пока есть запас; отпустите после полного расходования |
| Space | Прыжок |
| E | Точный шаг в Drag: нажимайте по надписи «ИДЕАЛЬНЫЙ ШАГ» |
| C | Смена камеры |
| R | Возврат к последней контрольной точке |
| Esc | Пауза / назад |
| M | Большая карта в свободном беге |

Скольжение: в четвёртой гонке на повороте зажмите W + S вместе с A/D (или стрелкой в нужную сторону). Так Фули продолжает движение в управляемом заносе и получает очки стиля. Если отпустить W, тормоз S по-прежнему останавливает персонажа. Победа в этом заезде определяется очками стиля, а после второго круга результат появляется сразу, без ожидания соперников. Каньон запускает крупный прыжок автоматически; при слишком медленном входе Фули восстанавливается на противоположной стороне. В тюнинге перетаскивание мышью вращает модель, колесо приближает её.

## Профиль и звук

Профиль хранится в `localStorage`, после гонок, покупок и настроек сохраняется автоматически. Хранилища разных браузеров, адресов и локальных файлов могут различаться. Перед переносом игры экспортируйте профиль в настройках. Импорт проверяет версию, деньги, уровни и массивы данных, затем запрашивает подтверждение замены.

Есть общая громкость, музыка и эффекты. Адреналин сопровождается резким «пшш», постоянным воздушным шипением при удержании Shift и затухающим сбросом после отпускания или исчерпания запаса. Громкость шипения подчиняется настройке «Эффекты». Озвучки персонажей в этой сборке нет: реплики представлены русскими субтитрами. Музыка и эффекты — локальные OGG, не синтез осцилляторами. Источники приведены в `CREDITS_AND_LICENSES.md`.

## Разработка

Node.js 24, Blender 4.3.2 (только для пересоздания модели), Python 3 (только для сервера). Игроку npm и Blender не нужны.

```sh
npm ci --cache /workspace/.npm-cache
npm run build
npm test
python3 -m http.server 8080 --bind 127.0.0.1
# В другом терминале, при доступном Chromium:
npm run test:browser
```

Путь к Chromium можно задать через `CHROMIUM_PATH`. Тест браузера использует существующий локальный сервер на порту 8080. Для повторной генерации модели: `blender -b -t 2 --python tools/models.py`, затем `npm run build`.

`js/core.js` — физика, правила, прогресс; `js/world.js` — Three.js, окружение, модели и камеры; `js/main.js` — интерфейс, звук, сохранения; `tools/models.py` — собственная скульптурная сетка и скелет в Blender. `js/game.bundle.js` уже собран.

## Границы версии

Художественное качество пока уровня процедурного прототипа: стилизованная модель Фули, варианты её сетки для гепардов, упрощённый скутер с водителем. Это не законченные канонические модели и не фотореалистичное окружение. В сценах есть бег и покой; отдельная лицевая анимация, полный набор анимаций прыжка, победы и поражения ещё не сделаны.

Вместо кампании примерно на сто событий реализованы 12. Не реализованы полноценные журналы/награды, многослойные рисунки на шерсти, подробная модель Kugoo Kirin EC-02, профессиональный монтаж кат-сцен, полный набор природных биомов, индивидуальные темы обоих боссов и все звуковые слои из ТЗ. Полный перечень проверок и ограничений — в `TEST_REPORT.md`. Проверок на Windows, реальном GPU и достижения 60 FPS не заявляется.
