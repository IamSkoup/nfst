# The Lion Guard — Underground Mobile

Это отдельная мобильная сборка браузерной игры. Исходная компьютерная версия не изменена. Все двенадцать гонок, карьера, тюнинг, музыка и сохранения остались на месте.

## Как запустить на телефоне

Распакуйте весь архив, не меняя структуру каталогов. Самый надёжный запуск — разместить папку игры на обычном статическом HTTPS-хостинге (например, GitHub Pages) и открыть `index.html` на телефоне в Chrome/Edge/другом современном браузере с WebGL. Интернет для игрового процесса после загрузки файлов не нужен, поскольку 3D-модель и ресурсы встроены или лежат рядом. Если открывать `index.html` через локальный `file://`, работа сохранений и мультимедиа зависит от браузера. Для запуска из локальной сети можно поднять простой HTTP-сервер на компьютере и открыть его IP с телефона.

Это не Android APK или приложение для App Store. На многих мобильных браузерах доступна команда «Добавить на главный экран», но её наличие зависит от браузера и размещения сайта.

## Сенсорное управление

Слева расположены повороты влево и вправо, справа — газ, тормоз, прыжок и адреналин («Рывок»). Удерживайте газ и поворот одновременно, используя два пальца. При дрифте одновременно удерживайте газ, тормоз и поворот. Над рулевыми кнопками есть действия «Пауза», «Камера», «Возврат», а в свободном беге — «Карта». В гонке Drag появляется отдельная кнопка «Ритм»; нажимайте её по подсказке.

Гонка работает в вертикальном и горизонтальном положении. Горизонтальное удобнее, потому что в кадре больше трассы. В меню можно прокручивать содержимое и листать список гонок вбок. Настройки содержат кнопку полноэкранного режима, если её поддерживает браузер.

Для мобильного устройства без прежнего профиля автоматически выбирается низкое качество графики. В настройках его можно повысить при достаточной производительности. Низкое качество отключает тени и уменьшает внутреннее разрешение 3D-сцены ради более ровной работы.

Сохранения браузера остаются совместимыми с компьютерной версией. Перенести профиль между устройствами можно через «Экспорт профиля» и «Импорт профиля» в настройках. Это важно: хранилища разных устройств и адресов не синхронизируются сами.

## Проверка и разработка

Предварительно собранная `js/game.bundle.js` позволяет играть без Node.js и npm. Разработчику для повторной сборки нужны `npm ci` и `npm run build`. Автоматические проверки запускаются командами `npm test`, `npm run test:mobile` и `npm run test:browser` (последние две требуют доступного тестового Chromium и локального сервера на `127.0.0.1:8080`).

Мобильная автоматическая проверка охватывает портретные и альбомные размеры, одновременные касания, камеру, паузу, карту и расположение кнопок. Она не заменяет проверку FPS и ощущения управления на конкретной модели телефона.
